## 推荐的桌宠实现

最协调的做法不是直接切换到上述二维插画，而是继续使用当前完整全身模型，另做一段约 3～5 秒的“小笼包投喂”动作：

1. 小蒸笼从画面下方出现；
2. 天依双手接住或拿起一个小笼包；
3. 送到嘴边，闭眼咬一口；
4. 脸颊轻微鼓起并咀嚼；
5. 满足地点头，回到原待机模式。

这样能保持桌宠主体画风、身高比例和点击区域一致，也能把“小笼包”做成后续可复用的投喂道具。
