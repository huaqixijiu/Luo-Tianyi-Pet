# 洛天依桌宠候选素材索引

这些文件按用途分类保存。原始 WebP、GIF、SVGA、透明 PNG 序列和模型文件均保留，`00_快速预览` 只是方便挑选的副本。

双击根目录的 `动画挑选器.html`，可以预览 46 个动作候选（包括原生动画和官方静态表情的程序动效预演）。每张卡片都能勾选“保留这个动画”，也可为日常、鼠标互动、音乐及系统提醒等 16 个动画状态分配素材，并勾选 18 个联动场景。选择会自动保存在本机浏览器中，最后可下载完整结果文本。

## 建议先看

1. `00_快速预览/01_十周年_旋转舞.webp`：全身 Q 版旋转动作，可作为音乐播放或拖拽状态。
2. `00_快速预览/02_九周年_音乐摇摆.webp`：1 秒循环的音乐摇摆动作。
3. `00_快速预览/03_代号洛天依_全息操作.webp`：可作为切歌、暂停、继续等操作反馈。
4. `00_快速预览/04_十周年_动作预览.png`：十周年点赞动画的代表画面。
5. `00_快速预览/05_心律共鸣_享受音乐.gif`：小尺寸透明动态表情。

## 文件夹说明

- `01_官方Q版模型`：已下载并解压 Vsinger 官方发布的“洛天依 V4 公式服 Q 版”PMX 模型；同时保留官方 RAR 原包与来源信息。
- `02_个性装扮动画原包`：Bilibili 个性装扮中的原始动画、背景和界面资源。
  - `35789_洛天依十周年`：Animated WebP、SVGA、74 帧透明 PNG 序列等。
  - `5766_洛天依9周年`：音乐摇摆 WebP、SVGA、透明 PNG 序列等。
  - `54182_代号洛天依`：全息操作 WebP、心形动画、透明 PNG 序列等。
  - `2156_洛天依8周年`：礼花/点赞 SVGA 与透明 PNG 序列。
- `03_官方表情包`：十周年、九周年、八周年、代号洛天依、收藏集及心律共鸣表情。
