# 模式二新添加动作母版

本目录保存用户提供的“晶蓝礼服版”720×720 透明 PNG 动作母版。原始逐帧文件只作为本地创作源保留，不进入安装包和 Git；运行时使用 `assets/animations/runtime/` 中的压缩图集，来源哈希记录在 `assets/animations/processed/晶蓝礼服_互动动作.meta.json`。

| 动作 | 本轮状态 | 用途 |
|---|---|---|
| 新比心 | 已接入 | 替换旧“手比心”，点击左右手触发 |
| 摸胸 | 已接入 | 点击 Chest 区域触发 |
| 摸裙边 | 已接入 | 点击 LowerBodySensitiveArea 区域触发 |
| 打哈欠 | 已接入 | 模式二无操作 1～5 分钟期间随机触发一次 |
| 鸭子坐 | 待接入 | 保留预览，等待后续互动规则 |
| 睡觉 | 待接入 | 保留预览，等待后续互动规则 |

“鸭子坐”和“睡觉”本轮没有运行时 ID，也不会被任何状态或身体区域触发。
