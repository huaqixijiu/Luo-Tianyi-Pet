## 同模型程序动作候选

`动作候选/` 中的 5 个动态 WebP 均由上述 32 帧完整全身待机确定性派生：

- `完整全身_轻轻鞠躬.webp`：脚底固定，人物轻微压低后恢复；
- `完整全身_开心跳跃.webp`：一次完整起跳、腾空和落地；
- `完整全身_左右探身.webp`：以脚底为轴向左右探身；
- `完整全身_害羞摇摆.webp`：小幅连续扭摆后回正；
- `完整全身_惊喜弹起.webp`：先蓄力压低，再快速弹起并收稳。

这些候选不替换角色、不重绘衣服和脸，也不引入其他表情包画风。它们属于整个人物的二维程序动效，因此可以解决“切换素材不协调”，但不能替代 PMX 骨骼级的真实挥手、抬腿或转头。源文件和生成算法均保留；运行
`tools/animation_tools/make_full_body_action_candidates.py --root .` 可以重新生成。
