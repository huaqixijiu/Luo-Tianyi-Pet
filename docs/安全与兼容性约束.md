# 安全与兼容性约束

> 本文中的条目是实现阶段的硬约束。新增原神、QQ、微信或其他应用联动时必须继续遵守。

## 1. 总体原则

桌宠只能作为独立的普通权限 Windows 桌面程序运行。它不得修改、注入、调试或分析被联动应用，不得模拟成游戏插件或覆盖层。

默认要求：

- 不申请管理员权限；
- 不安装内核驱动或系统服务；
- 不修改游戏、QQ、微信或网易云音乐文件；
- 不绕过反作弊、沙箱或应用安全机制；
- 不读取其他进程内存；
- 不枚举其他进程模块；
- 不创建指向游戏进程的长期句柄；
- 不进行 DLL 注入、远程线程、代码补丁或 API Hook；
- 不挂钩 DirectX、OpenGL 或 Vulkan 渲染；
- 不抓包、不代理流量、不读取聊天数据库；
- 不截取游戏画面或聊天窗口来识别状态。

## 2. 原神检测

原神启动检测只允许使用 Windows 提供的进程生命周期通知，例如 WMI 的进程启动事件。监听内容限制为进程名、进程标识和启动/结束时间。

禁止：

- 打开原神进程读取内存；
- 查询游戏模块、线程、窗口内容或反作弊组件；
- 向游戏窗口发送键盘、鼠标或窗口消息；
- 把桌宠窗口附着到游戏窗口；
- 将桌宠实现为游戏内 Overlay；
- 为保持显示而尝试绕过独占全屏或反作弊限制。

桌宠是普通的透明顶层窗口。原神启动动画可以短暂申请 Windows `TopMost`，但必须设置为不激活窗口，不抢键盘焦点。检测到受保护游戏处于独占全屏时，应停止临时覆盖、延后提醒或保持在桌面层。

## 3. 游戏安全模式

配置中的受保护进程位于前台时自动启用游戏安全模式：

- 暂停所有 `SendInput`、模拟快捷键和自动鼠标操作；
- 不为 QQ、微信等普通通知申请临时置顶；
- 桌宠不得抢焦点；
- 可选择变为鼠标穿透；
- 降低后台检测频率和动画帧率；
- 仅保留进程退出检测与本地状态记录；
- 退出游戏后恢复用户此前的桌宠设置。

因此，网易云快捷键在受保护游戏前台时默认不由桌宠模拟发送。若以后需要游戏内控制，应优先研究 Windows 媒体命令或让用户使用真实媒体键，而不是向游戏前台发送组合键。

## 4. QQ 与微信

允许的检测来源：

- 用户授权的 Windows 通知访问；
- Windows Shell 的任务栏窗口闪烁事件；
- 应用进程是否位于前台。

禁止：

- 读取聊天数据库、缓存文件或日志；
- 注入 QQ/微信进程；
- 使用 UI 自动化遍历联系人和消息列表；
- OCR 截取聊天窗口；
- 抓取或解密网络流量；
- 在通知气泡中保存联系人或消息正文。

桌宠只保存来源类别和时间，例如“QQ，2026-08-30 10:30”。用于去重的数据应在内存中短期保存，不写入长期日志。

## 5. 网易云音乐与系统输入

网易云音乐控制使用用户自行配置的全局快捷键。实现时必须：

- 明确显示当前配置的快捷键；
- 禁止用户配置系统保留组合键；
- 设置发送频率限制，避免按键风暴；
- 受保护游戏前台时暂停模拟输入；
- 不向未知前台窗口发送普通字符；
- 不读取网易云进程内存或私有数据。

音乐状态检测只使用 Windows Core Audio 或系统媒体会话。系统媒体会话是 Windows 能力，不是网易云私有接口。

## 6. 窗口行为

- 所有临时置顶均使用引用计数或请求令牌；
- 动画结束只释放自己的置顶请求；
- 永久置顶以用户最新设置为准；
- 临时置顶窗口使用不激活样式；
- 全屏应用前台时默认不显示普通通知覆盖；
- 崩溃恢复时默认撤销临时置顶，避免遗留遮挡窗口；
- 支持紧急隐藏快捷键和托盘菜单退出。

## 7. 权限、日志与发布

- 默认普通用户权限运行；
- 首次申请通知访问时说明用途；
- 日志不记录聊天内容、窗口标题或用户输入；
- 可提供“导出诊断信息”，导出前展示具体字段；
- 发布包应包含可验证的版本号和文件哈希；
- 后续正式发布可考虑代码签名，减少系统安全提示；
- 第三方联动必须可以单独关闭，并提供进程名白名单而不是扫描所有软件。

## 8. 新增应用联动检查表

新增任何游戏或通讯软件前，需要确认：

1. 是否只使用操作系统公开事件；
2. 是否完全不读取目标进程内存和文件；
3. 是否不向目标应用注入代码或挂钩；
4. 是否不在全屏状态抢焦点或强制覆盖；
5. 是否不收集消息正文等隐私数据；
6. 是否能由用户单独关闭；
7. 是否有防抖、冷却和恢复策略；
8. 目标应用失效或升级后，桌宠是否仍能安全降级。

任意一项不能满足时，该联动默认不实现。
