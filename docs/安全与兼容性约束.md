# 安全与兼容性约束

> 本文中的条目是实现阶段的硬约束。新增原神、QQ、微信或其他应用联动时必须继续遵守。

## 1. 总体原则

桌宠只能作为独立的普通权限 Windows 桌面程序运行。它不得修改、注入、调试或分析被联动应用，不得模拟成游戏插件或覆盖层。

默认要求：

- 不申请管理员权限；
- 不安装内核驱动或系统服务；
- 不修改游戏、QQ、微信或网易云音乐文件；
- 不绕过反作弊、沙箱或应用安全机制；
- 不读取其他进程内存；
- 不枚举其他进程模块；
- 不创建指向游戏进程的长期句柄；
- 不进行 DLL 注入、远程线程、代码补丁或 API Hook；
- 不挂钩 DirectX、OpenGL 或 Vulkan 渲染；
- 不抓包、不代理流量、不读取聊天数据库；
- 不截取游戏画面或聊天窗口来识别状态。

## 2. 原神检测

原神启动检测只允许使用 Windows 提供的普通权限进程枚举或生命周期通知。监听内容限制为已配置的原神进程名、进程标识和启动/结束时间；若某种通知机制在普通用户权限下不可用，必须回退到低频只读枚举，不能要求提权。

禁止：

- 打开原神进程读取内存；
- 查询游戏模块、线程、窗口内容或反作弊组件；
- 向游戏窗口发送键盘、鼠标或窗口消息；
- 把桌宠窗口附着到游戏窗口；
- 将桌宠实现为游戏内 Overlay；
- 为保持显示而尝试绕过独占全屏或反作弊限制。

桌宠是普通的透明顶层窗口。原神启动动画可以短暂申请 Windows `TopMost`，但必须设置为不激活窗口，不抢键盘焦点。检测到受保护游戏处于独占全屏时，应停止临时覆盖、延后提醒或保持在桌面层。

原神后台“拜托”彩蛋只允许在原神进程存在且前台进程不是原神时显示。前台判断只使用 `GetForegroundWindow` 对应的进程标识，不读取窗口画面或游戏内部状态。随机位置必须限制在 Windows 工作区内并保持角色完整可见；动画播放后恢复原位置和用户原有置顶设置。原神重新位于前台、独占全屏、锁屏或进程退出时，立即暂停或取消尚未显示的彩蛋。

## 3. 游戏安全模式

配置中的受保护进程位于前台时自动启用游戏安全模式：

- 暂停所有 `SendInput`、模拟快捷键和自动鼠标操作；
- 不为 QQ、微信等普通通知申请临时置顶；
- 桌宠不得抢焦点；
- 可选择变为鼠标穿透；
- 降低后台检测频率和动画帧率；
- 仅保留进程退出检测与本地状态记录；
- 退出游戏后恢复用户此前的桌宠设置。

因此，网易云快捷键在受保护游戏前台时默认不由桌宠模拟发送。若以后需要游戏内控制，应优先研究 Windows 媒体命令或让用户使用真实媒体键，而不是向游戏前台发送组合键。

## 4. QQ 与微信

允许的检测来源：

- 用户授权的 Windows 通知访问；
- Windows Shell 的任务栏窗口闪烁事件；
- 应用进程是否位于前台。

首选通知监听需要 MSIX 包身份、清单中的 `uap3:userNotificationListener` 能力以及用户在设置页
主动授权。免安装版本没有包身份时必须显示“需要 MSIX”，不得反复请求、伪造已授权状态或改用
更高权限方案。平台层只允许读取通知的应用标识、应用显示名和创建时间；禁止访问通知负载对象。

禁止：

- 读取聊天数据库、缓存文件或日志；
- 注入 QQ/微信进程；
- 使用 UI 自动化遍历联系人和消息列表；
- OCR 截取聊天窗口；
- 抓取或解密网络流量；
- 在通知气泡中保存联系人或消息正文。

桌宠只保存来源类别和时间，例如“QQ，2026-08-30 10:30”。用于去重的数据应在内存中短期保存，不写入长期日志。

## 5. 网易云音乐与系统输入

网易云音乐控制使用用户自行配置的全局快捷键。实现时必须：

- 明确显示当前配置的快捷键；
- 禁止用户配置系统保留组合键；
- 设置发送频率限制，避免按键风暴；
- 受保护游戏前台时暂停模拟输入；
- 不向未知前台窗口发送普通字符；
- 不读取网易云进程内存或私有数据。

发送实现只允许使用公开的 `SendInput` 键盘输入能力。发送前通过
`GetForegroundWindow` 和 `GetWindowThreadProcessId` 取得前台进程类别；查询失败
时按安全失败处理。通过 `GetAsyncKeyState` 发现用户仍按住快捷键中的任一键或
Ctrl/Alt/Shift/Windows 修饰键时不得发送。一次发送必须包含成对的按下/抬起事件，
若系统只接受部分事件，只能尝试抬起本次组合涉及的键并报告失败，不能释放其他键。

音乐状态检测只使用 Windows Core Audio。曲目信息优先来自系统媒体会话；系统媒体会话
是 Windows 能力，不是网易云私有接口。若目标网易云版本没有注册系统媒体会话，允许
通过 Windows 桌面管理器读取 `cloudmusic.exe` 的顶层主窗口标题作为只读兜底，但必须：

- 只匹配配置中的网易云目标进程，不读取其它应用窗口标题；
- 只读取顶层标题栏，不使用 UI 自动化遍历窗口正文，不截图或 OCR；
- 不读取进程内存、模块、文件、网络或网易云私有数据；
- 曲名和歌手只保存在内存中，不写日志、不保存历史、不上传；
- 标题为空、只有“网易云音乐”或格式无法可靠识别时安全降级为“暂未读取到歌曲名称”。

系统主音量只允许通过 Windows Core Audio 的默认多媒体输出端点读取和调整，不使用
键盘模拟、全局鼠标 Hook、驱动或第三方音频注入。滚轮操作只在指针位于桌宠窗口时由
WPF 自身事件接收；调整前复用前台受保护进程检查，查询失败或受保护游戏前台时不写入
音量。外部音量反馈只读取归一化主音量和静音状态，不读取、录制或保存任何音频内容；
安全模式下更新内部基线但不显示覆盖动画，离开游戏后也不得补播旧反馈。

开机自启动默认关闭，只允许在用户主动切换后操作
`HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run` 中本产品自己的单一值。
不得安装 Windows 服务、计划任务、驱动或写入其他用户/机器级启动位置；关闭选项时只删除
本产品值，不枚举或修改其它启动项。

## 6. 文件拖放与回收站

- 只把桌宠自己的 OLE `IDropTarget`/框架拖放事件作为文件来源，不安装全局 Shell Hook、鼠标 Hook 或资源管理器扩展；
- 只接受 `CF_HDROP` 中可以解析为真实文件系统项目的路径，不读取被拖文件内容；
- 删除语义必须通过 Windows Shell `IFileOperation` 请求移入回收站，并启用允许撤销/回收站标志；
- 回收站不可用、权限不足、项目来自不支持的虚拟来源或 Shell 操作失败时，必须原样保留目标；
- 禁止永久删除回退，禁止 `File.Delete`、`DeleteFile`、命令行删除和 Shift 永久删除语义；
- 拖入文件夹或一次超过 10 个项目时再次确认；
- 受保护游戏位于前台、系统锁屏或桌宠处于鼠标穿透模式时禁用文件接收；
- 日志只记录项目数量、成功/失败和错误代码，不记录完整文件名、路径或文件内容。

## 7. 窗口行为

- 所有临时置顶均使用引用计数或请求令牌；
- 动画结束只释放自己的置顶请求；
- 永久置顶以用户最新设置为准；
- 临时置顶窗口使用不激活样式；
- 全屏应用前台时默认不显示普通通知覆盖；
- 崩溃恢复时默认撤销临时置顶，避免遗留遮挡窗口；
- 支持紧急隐藏快捷键和托盘菜单退出。

## 8. 权限、日志与发布

- 默认普通用户权限运行；
- 首次申请通知访问时说明用途；
- 日志不记录聊天内容、窗口标题或用户输入；
- 可提供“导出诊断信息”，导出前展示具体字段；
- 发布包应包含可验证的版本号和文件哈希；
- 后续正式发布可考虑代码签名，减少系统安全提示；
- 第三方联动必须可以单独关闭，并提供进程名白名单而不是扫描所有软件。

## 9. 新增应用联动检查表

新增任何游戏或通讯软件前，需要确认：

1. 是否只使用操作系统公开事件；
2. 是否完全不读取目标进程内存和文件；
3. 是否不向目标应用注入代码或挂钩；
4. 是否不在全屏状态抢焦点或强制覆盖；
5. 是否不收集消息正文等隐私数据；
6. 是否能由用户单独关闭；
7. 是否有防抖、冷却和恢复策略；
8. 目标应用失效或升级后，桌宠是否仍能安全降级。

任意一项不能满足时，该联动默认不实现。
