## 1. 项目目标

制作一个仅在 Windows 本地运行的洛天依 Q 版桌宠，包含透明桌面窗口、两种待机显示模式、动画状态机、鼠标身体区域互动、网易云音乐快捷键控制、音乐与系统音量检测、QQ/微信来源提醒、原神低权限联动，以及把用户主动拖入的文件移入 Windows 回收站。

## 2. 已接管的默认技术决策

- C# + .NET 10 LTS + WPF；
- Windows 10 1809 及更高版本，重点验证 Windows 11；
- 普通用户权限运行，不以管理员身份启动；
- 首先提供自包含免安装构建，通知监听稳定后补充 MSIX 包；
- 状态机与 Windows 平台能力分层；
- GIF、动态 WebP、SVGA 和程序动效在构建阶段转换为统一运行时动画描述；
- 原始素材始终保留，派生资产写入 `assets/`；
- 配置采用带版本号的 JSON，并支持将旧配置迁移到新版本；
- 单实例运行，设置和位置按 Windows 用户保存在本地应用数据目录；
- 默认不开机自启，用户可在设置中主动开启。

这些默认决策由 Codex 负责维护。只有明显改变用户体验、隐私权限或安全边界的选择需要再次询问用户。

## 4. 已确认但仍需实现时细化的规则

- 音乐从暂停或停止进入播放时按歌手分类：洛天依独唱/合唱随机“享受音乐”或“音乐摇摆”，其它或未知歌手固定“享受音乐”陪听；音乐停止后恢复用户选择的“嘿嘿”或完整全身模式。
- 音乐状态临时覆盖显示模式，但不修改用户的模式选择。
- 暂停动画期间恢复播放时立即中断暂停反馈，并重新随机选择一个音乐持续动画。
- 用户从菜单退出桌宠时播放一次“裂开晃动”；系统关机、注销或崩溃路径不等待该动画。
- 完整全身身体区域只在完整全身待机可见且没有一次性反应覆盖时接受点击。
- 一次性反应过期后不补播；同源通知短时间合并。
- 原神等受保护进程位于前台时，停用模拟输入、文件接收和普通临时置顶。
- 普通全屏应用前台时桌宠退到桌面层；受保护游戏独占全屏时可隐藏并降低帧率。
- 调高音量播放原版“共鸣之声”，调低音量播放倒放版；静音和解除静音暂不播放动画。
- 操作失败或超时统一播放“呜呜晃动”，同时显示与失败原因对应的气泡文字。
- 完整全身模式点击眼睛播放“心软软”，点击脚播放“糟了晃动”。
- 完整全身模式点击普通身体部位固定播放“十二周年·抱抱”；脸部播放“贴贴”，嘴部播放“啾啾”；完成头顶往返摸头后播放“天依游学记·国乐季 · 摸摸”。

## 6. 当前风险

1. 透明窗口已移除阻塞式 `DragMove` 并改为捕获鼠标后的手动移动；当前按虚拟桌面边界夹取，但跨 DPI 显示器仍需实测。
2. QQ/微信提醒依赖 MSIX 包身份和用户授予 Windows 通知访问权限；开发证书与 `0.1.0.1` 已在本机安装。通知监听不会再于未授权启动阶段自动探测；来源应用关闭系统通知时也不能保证检测。
3. 透明异形窗口的像素命中、拖放扩展区域和点击穿透需要实际 Windows 验证。
4. 全身模型和表情包画风不同；音乐和身体短按反应已经复用遮罩式过渡，后续新素材仍需逐项检查缩放和遮罩覆盖范围。
5. 文件回收站功能具有数据操作风险，只能用临时文件测试，且失败不能永久删除。
6. 当前网易云快捷键使用首轮默认组合；若用户在网易云中改过全局快捷键，需要在后续设置页同步修改，否则桌宠只能确认“输入已发送”，不能保证播放器响应。
7. 当前网易云版本没有注册 Windows 系统媒体会话，曲名依赖其主窗口标题兜底；如果网易云以后隐藏标题、改格式或启用不带标题的迷你模式，桌宠只能安全降级为“暂未读取到歌曲名称”。
8. 系统音量服务当前绑定启动时的默认多媒体输出设备；运行期间切换默认声卡会安全降级为暂不可用，自动重建端点留到设置/设备切换完善项。
9. 设置窗口已能真实启动且 XAML、构建和操作逻辑通过验证，但 Windows Graphics Capture 对该窗口连续返回 `0x80004002`，本轮没有取得自动截图；仍需用户实际看一次 100%/125%/150% DPI 下的布局。
10. 会话解锁和电源恢复已通过隔离 QA 事件验证；为避免中断用户，本轮没有真的锁屏或让电脑睡眠，仍需后续在真实恢复路径做一次人工验收。
11. 原神联动的调度、普通权限枚举和真实 WPF 展示已隔离验证；为避免账号与反作弊风险，本轮没有启动原神，也没有在真实游戏前台/全屏中运行桌宠，最终兼容性仍需用户后续自愿观察。
12. 便携测试 EXE 没有商业代码签名，其他电脑可能显示 SmartScreen“未知发布者”；测试者应先核对随包 SHA-256。程序级清理不触碰 Windows 自身可能保留的下载、SmartScreen、安全扫描或系统事件记录。
13. 左右及底部墙面触发条已通过工作区计算和可访问树验证；跨 DPI、多显示器边界的实际悬停、拖出手感仍需人工验收。
