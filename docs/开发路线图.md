# 开发路线图

路线图按可运行的纵向里程碑推进。未达到验收条件的里程碑不能标记完成。

## M0：环境和工程骨架

状态：已完成（2026-08-30）。

目标：仓库可以在新环境中还原、编译和启动。

- 安装并验证 .NET 10 SDK；
- 创建解决方案、WPF 应用、核心库和测试项目；
- 加入统一构建设置和基础 CI；
- 创建透明、无边框、不进任务栏的主窗口；
- 建立配置加载、日志、单实例和异常兜底。

验收：`dotnet build` 和 `dotnet test` 成功；窗口可启动、拖动和正常退出；普通用户权限下运行。

## M1：动画播放器和两种待机模式

状态：已完成（2026-08-30）。

目标：用真实素材完成第一个稳定桌宠循环。

- 建立动画清单和 AssetCompiler 原型；
- 播放“嘿嘿”、完整全身待机、享受音乐和音乐摇摆；
- 支持透明边界、锚点、循环、倍速和结束回调；
- 双击切换迷你/完整全身模式；
- 缺失或损坏素材时显示安全占位，不崩溃。

验收：连续运行 30 分钟无明显内存增长；两种模式可可靠切换；0.5 倍速素材时序正确。

## M2：状态机和鼠标互动

状态：已完成（2026-08-30）。状态机、手势互斥、拖拽/落地、身体命中、短按区域反应、约 600 毫秒往返摸头和反应后防误触均已接入；后续仍可按用户体感微调参数，但不再阻塞 M3。

目标：动画不会因事件重叠而回错状态。

- 实现显示模式、持续状态、一次性反应三维状态模型；
- 实现优先级、打断、恢复、合并和冷却；
- 完成迷你/完整全身拖拽；迷你模式带落地回弹，完整全身模式松手直接恢复；
- 建立身体命中调试叠层；
- 完成脸、摸头、手、敏感区域和脚部互动。

验收：状态机自动测试覆盖关键冲突；双击不会误触单击；拖拽不会误触身体区域；所有反应结束回到正确模式。

## M3：音乐和系统音量

状态：已完成（2026-08-30）。已完成 `cloudmusic.exe` Core Audio 只读检测、播放状态防抖、运行时状态机接入、带游戏安全拦截的全局快捷键、三键悬浮控制条、切歌等待/确认闭环、歌手驱动的洛天依唱歌/普通陪听动画，以及系统音量滚轮控制、外部变化反馈、防抖和独立设置窗口。

目标：桌宠能够检测、控制并正确反馈网易云音乐。

- Core Audio 检测 `cloudmusic.exe` 音频会话；
- 有声宽限、暂停、恢复和播放器退出状态；
- 用户配置网易云全局快捷键；
- 上一首、下一首、播放/暂停及等待/成功/超时反馈；
- 网易云未运行时由播放按钮安全冷启动，使用静态加载画面等待真实有声；
- 滚轮和设置滑块调整系统音量；
- 外部音量变化反馈和防抖。

验收：没有网易云、网易云退出、歌曲静音间隙、快捷键失败时均可安全恢复；受保护应用前台时不发送模拟输入。

## M4：时间、原神和消息提醒

目标：低权限外部联动稳定且不打扰全屏应用。

状态：进行中。时间场景、原神低权限联动、QQ/微信来源提醒原型、边缘躲藏体验修正，以及带通知能力的 x64 自包含签名 MSIX 均已完成。通知真实授权和多显示器边缘手感仍待用户验收。

- 启动和休眠恢复的时间问候；
- 长时间无输入睡眠与恢复；
- 原神启动三遍反应和后台低频彩蛋；
- 全屏及受保护游戏安全模式；
- Windows 通知访问说明、授权和拒绝降级；
- QQ/微信来源提醒、前台抑制和合并。

验收：不使用注入、Hook、内存读取或管理员权限；游戏前台不抢焦点；权限拒绝不影响其他功能。

## M5：文件拖放和回收站

目标：实现明确、可撤销且不会永久删除的投放体验。

- [x] WPF/OLE `CF_HDROP` 文件接收；
- [x] “给我”播放一次后定格、400 ms 停留门槛和离开取消；
- [x] Shell `IFileOperation` 回收；
- [x] 文件夹和超过 10 项批量投放二次确认；
- [x] 无效路径、网络位置、回收失败和部分失败的安全降级；
- [x] 受保护游戏前台、全屏、锁屏和边缘隐藏状态下禁用；
- [ ] 用户确认“来喽 → 十一周年干饭”组合后，接入文件图标缩小与吃文件反馈；
- [ ] 设计并验证不使用全局 Hook 的桌面自主删除观察与删除前图标位置缓存；
- [ ] 设置页总开关与首次使用说明。

验收：只使用临时测试文件；成功项目能从回收站恢复；所有失败路径保留原项目；代码中不存在永久删除回退。

## M6：设置、可靠性和发布

目标：形成可长期使用和恢复的个人版本。

- 设置页、托盘菜单、置顶、隐藏、开机启动和快捷键配置；
- 多显示器、DPI、锁屏、睡眠和显示器变化；
- 设置迁移、崩溃恢复和诊断导出；
- 动画池和剩余表情映射；
- 性能调优、长时间测试、自包含发布和 MSIX；
- 发布说明、版本号和文件哈希。

验收：全新 Windows 用户环境可安装或解压运行；设置可迁移；完整回归测试通过。

当前已提前完成：托盘菜单、永久置顶、开机自启动和设置入口。开机自启动默认关闭，用户可随时撤销。

## 工作优先级

当前进入 M4 的通知实机验收阶段；MSIX、证书和未授权安全启动均已验证。唯一下一项是用户在设置页亲自点击通知授权，随后只用测试消息验证 QQ/微信来源分类、前台抑制、3 秒去重及全屏延后。另已提供不需要管理员权限、数据只写在包内 `UserData` 的便携测试 ZIP，供其他人测试除通知监听之外的功能。
