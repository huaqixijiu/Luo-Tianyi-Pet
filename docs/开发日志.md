## 2026-08-31：修复网易云切歌时偶发安全退出

### 定位

- 从用户正在运行的 `0.1.0.5` 便携版日志确认，切歌约 11 秒后 WPF Dispatcher 收到 `ArgumentOutOfRangeException` 并进入全局安全退出；异常前发生了曲目元数据切换和 Core Audio 播放会话停止/恢复；
- 根因是网易云切歌时会短暂销毁或重建音频会话。桌宠在 `SessionCollection.Count` 与按下标取会话之间遇到集合变化，或读取到音频端点的瞬态边界值时，旧实现只捕获 COM/设备异常，越界异常会冒到界面线程；
- 问题位于公开 Core Audio 只读探测适配器，不涉及快捷键发送、歌曲元数据、网易云进程内存或网络接口。

### 修复

- Core Audio 枚举现在将会话集合变化产生的 `ArgumentOutOfRangeException` 视为一次不可用采样，并继续下一轮检测；
- 峰值采样拒绝 `NaN`/无穷值，有限的轻微越界统一夹取到 `0～1`，避免平台瞬态数值传入严格领域模型；
- 主窗口音乐检测再增加一层故障边界：参数、无效状态、COM 和权限类适配器异常仅跳过当前 250 ms 轮询，保留原音乐/待机状态并继续重试，不再触发应用退出；
- 最小隐私日志增加异常目标类型、方法和参数名，仍不记录异常消息、歌曲名、歌手名、窗口标题、用户输入或路径。
