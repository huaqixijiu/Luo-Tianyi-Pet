# 决策记录

本文件追加重要决策。新决定可以取代旧决定，但要注明替代关系，不能删除历史原因。

## ADR-001：使用 C#、.NET 10 LTS 和 WPF

- 日期：2026-08-30
- 状态：已采用
- 决定：主程序采用 C#、.NET 10 LTS 和 WPF。
- 原因：项目只面向 Windows，并大量依赖透明窗口、Win32、Core Audio、OLE、COM 和 Shell 能力；WPF 的窗口互操作成熟，适合先完成个人桌宠。
- 影响：不追求跨平台；现代 Windows API 通过平台适配层接入。

## ADR-002：把仓库作为跨对话记忆

- 日期：2026-08-30
- 状态：已采用
- 决定：`AGENTS.md` 规定每轮恢复流程，`docs/项目总控.md` 保存当前状态，开发日志保存验证历史。
- 原因：聊天可能变长、压缩或切换任务，不能依赖模型对旧对话的隐式记忆。
- 影响：每个可交付变更必须同步更新项目总控和开发日志，否则不算完成。

## ADR-003：原始素材和运行时素材分离

- 日期：2026-08-30
- 状态：已采用
- 决定：`候选素材_官方/` 只保存原始来源；`assets/` 保存可追溯的运行时派生资产。
- 原因：现有格式和画布差异较大，直接在 UI 中混用解码器会增加故障和性能风险。
- 影响：建立资产编译工具、动画清单、来源哈希和转换参数。

## ADR-004：显示模式、持续状态和一次性反应分离

- 日期：2026-08-30
- 状态：已采用
- 决定：不使用一个枚举表示桌宠全部状态；调度器从三个正交状态生成播放计划。
- 原因：QQ提醒、音乐、睡眠和用户选择模式会交叉；单一状态容易在动画结束时恢复错误。
- 影响：所有平台联动只能发领域事件，不能直接命令窗口播放并写死返回动画。

## ADR-005：安全降级优先于功能命中率

- 日期：2026-08-30
- 状态：已采用
- 决定：受保护应用前台、通知权限拒绝、回收站不可用或媒体结果不确定时，功能可以不触发，但不能绕过权限或给出错误成功反馈。
- 原因：账号安全、文件安全和隐私高于动画完整性。
- 影响：每个外部联动必须提供禁用、超时、取消和恢复路径。

## ADR-006：音乐状态临时覆盖显示，不修改用户模式选择

- 日期：2026-08-30
- 状态：已采用
- 决定：音乐开始后播放“享受音乐”并进入“音乐摇摆”；音乐停止后恢复用户此前选择的迷你或完整全身模式。
- 原因：保留已经确认的音乐专属待机，同时不让音乐事件永久改变用户的交互选择。
- 影响：设置中需要分别保存 selected display mode 和 resolved playback state。

## ADR-007：运行时统一使用透明 PNG 图集和帧时序清单

- 日期：2026-08-30
- 状态：已采用
- 决定：选定的 GIF、动态 WebP 和 PNG 在构建前编译为透明 PNG 图集；WPF 根据带来源哈希的 JSON 清单逐帧裁切播放。
- 原因：WPF 对现有动画格式的原生支持不一致；统一图集可以准确保留透明度、毫秒级帧时长、循环次数和结束回调，并减少运行时解码器依赖。
- 影响：新增可复现的图集生成脚本和清单校验器；原始文件继续保留，图集通过 Git LFS 管理；需要在 M1 完成内存稳定性验证。

## ADR-008：每次播放会话随机选择一个音乐持续动画

- 日期：2026-08-30
- 状态：已采用；覆盖 ADR-006 中“享受音乐后固定进入音乐摇摆”的两阶段描述，ADR-006 的显示模式恢复约束继续有效。
- 决定：每次从暂停或停止进入播放状态时，在 0.5 倍速“享受音乐”和“音乐摇摆”中随机选择一项，并让它在整个播放会话中循环；暂停后继续播放重新选择。
- 原因：两种素材人物大小、服装和画风不同，播放中途强制切换仍会让体验割裂；按播放会话选择可保留随机性并避免会话内换装。
- 影响：两项素材都必须支持无限循环；持续状态保存当前会话选中的动画，音乐停止后仍恢复用户原本选择的“嘿嘿”或完整全身模式。

## ADR-009：使用只读 Core Audio 会话峰值判断网易云是否有声

- 日期：2026-08-30
- 状态：已采用
- 决定：通过 Windows Core Audio 枚举默认多媒体输出设备的会话，以公开的会话进程号匹配 `cloudmusic.exe`，读取归一化峰值；使用 `NAudio.Wasapi` 3.0.1 作为薄封装。默认每 250 毫秒读取一次，峰值达到 0.001 立即视为播放，连续 1.5 秒无声才视为停止。
- 原因：用户要求不接网易云私有接口；单纯检查进程无法区分播放和暂停，而公开音频会话峰值无需注入、Hook、内存读取或网络监听。
- 影响：功能可以在运行时配置中单独关闭；会话消失立即停止，临时探测失败保留上次状态并重试；不记录进程号、峰值或歌曲信息。真实播放器在不同输出设备、静音歌曲和独占输出下仍需端到端验证。
