## 交付内容

- 月历采用日期、农历日、节日、事项圆点和右侧当天事项；重复点当天或点击 × 收起侧栏。班休为任意星期设置及日期多选覆盖，休红班蓝。周历为周一至周日的事项列。
- 每个事项独立设置提醒，铃铛在时间前；名称和单行备注分开，新建默认不开提醒，首次开启提前提醒为30分钟，可改分钟数。未指定时间不会产生午夜提醒。
- 闹钟页只有三个按数据出现的分组；同一新建弹窗包含指定时间/倒计时。倒计时沿用上次值、5/15/30分钟和1小时快捷值、时分秒输入与按钮/滚轮，最大24小时，可暂停继续和取消。
- 保留单日、整组及多组删除，批量管理入口位于事项更多菜单；没有单独的主导航页。删除范围须确认，修改日期同步撤销旧调度。
- 提前知道了保留正式提醒并形成聚合胶囊；本次不再提醒只取消该次，不影响未来重复。正式提醒提供知道了/稍后10分钟。声音、音色、音量和可选动画统一设置。
- 实际提示仍在原音乐岛/人物下方；新管理胶囊在人物周边避让。音乐岛实现与原素材未修改。
