## 动画配置字段

正式配置建议为每个动画保存以下信息：

```text
id
显示名称
源文件相对路径
循环方式
默认循环次数
是否允许中断
冷却时间
透明边界裁切
锚点位置
推荐场景标签
```

动画源文件继续保存在 `候选素材_官方/`。在最终映射确定前不移动或重命名原始素材，以免破坏动画挑选器中的相对路径。
