# 洛天依桌宠

一个面向 Windows 的洛天依 Q 版桌面宠物项目。

计划功能包括透明置顶桌宠、待机与鼠标互动动画、网易云音乐全局快捷键控制、基于 Windows 音频会话的播放状态检测，以及随音乐响度和节拍变化的舞蹈动作。

## 当前内容

- `候选素材_官方/`：官方模型、个性装扮动画、动态表情及动画挑选器。
- 动画候选暂时保留完整素材库，具体场景映射将在程序设置中配置。

## 资源管理

图片、动画、模型和压缩包使用 Git LFS 管理。克隆本项目时需要安装 Git LFS，并运行：

```powershell
git lfs install
git lfs pull
```
