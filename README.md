# 洛天依桌宠

一个面向 Windows 的洛天依 Q 版桌面宠物项目。项目目前处于需求、动画挑选和技术验证阶段。

计划功能包括透明桌宠窗口、待机与鼠标区域互动、网易云音乐全局快捷键控制、系统音量联动、音乐播放状态检测、QQ/微信简要提醒，以及可配置的应用启动反应。

## 已确认的场景

- 网易云音乐：上一首、下一首、播放和暂停，继续使用全局快捷键，不接入网易云接口。
- 音乐动画：检测网易云音频会话，播放时进入音乐摇摆或舞蹈状态。
- 音量动画：桌宠可以调节系统音量，同时响应键盘、任务栏和耳机旋钮造成的外部音量变化。
- 待机模式：默认以较小的“嘿嘿”待机；双击切换到完整全身互动模式，再次双击切回；长时间无操作使用“十周年·晚安浮动”。
- 原神启动：播放“你不许玩”三次并短暂置顶，结束后恢复用户原有的置顶选择。
- 原神后台彩蛋：原神进程仍在运行但不位于前台时，大约每小时在安全随机位置播放一次“心律共鸣·拜托”，播放后回到原位置。
- QQ/微信提醒：只显示来源应用，不读取消息正文；动画使用“代号洛天依·好奇摇摆”。
- 时间问候：早晨使用“早安浮动”，中午使用“干饭弹跳”，下午使用“十周年·摸鱼漂浮”，夜间使用“眠了呼吸”。
- 鼠标互动：支持头部、手部、身体等区域点击，以及拖拽、落地回弹和滚轮调音量。
- 文件互动：把桌面文件拖近桌宠时播放“给我”，松手到角色身上后通过 Windows 原生接口移入回收站。

## 安全原则

项目不向游戏或聊天软件注入 DLL，不读取进程内存，不安装驱动，不挂钩游戏渲染，不抓取聊天数据库或网络流量。检测原神仅使用 Windows 提供的进程生命周期事件；受保护游戏位于前台时，停止模拟键盘输入和强制覆盖。

## 目录

```text
洛天依桌宠/
├─ config/             可编辑的场景规则与默认设置
├─ docs/               需求、安全约束和动画映射
├─ assets/             已确认用于运行时的处理后素材
├─ 候选素材_官方/      官方模型、动画、表情与动画挑选器
├─ .gitattributes      Git LFS 资源类型
└─ .gitignore          构建产物和本地临时文件忽略规则
```

源代码目录会在技术方案确定后建立，避免现在提前固定框架结构。

## 资源管理

图片、动画、模型和压缩包使用 Git LFS 管理。克隆本项目时需要安装 Git LFS，并运行：

```powershell
git lfs install
git lfs pull
```
